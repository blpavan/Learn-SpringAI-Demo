KnowledgeDesk Release Notes - May 2026

New Features

The support portal now allows employees to attach screenshots to VPN, device, and software tickets. Attachments are scanned before agents can download them.

Operational Changes

High-priority incidents must include affected user count, business impact, and the first failed timestamp. Missing impact details should be requested before escalation.

Known Issues

Some macOS users may see stale VPN status after waking from sleep. Restarting the VPN client refreshes the connection state.
